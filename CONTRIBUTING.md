# Contributing

1. Fork the repository and create a focused branch.
2. Run `flutter pub get`, `flutter analyze`, and `flutter test` before opening a PR.
3. Keep user-visible text in `assets/l10n/en.json` and `assets/l10n/ar.json`.
4. Add tests for behavior changes.
5. Do not commit signing keys, passwords, generated APKs, or copyrighted media.
