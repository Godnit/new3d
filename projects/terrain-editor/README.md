# Terrain Studio — Phase 1

محرر خرائط ثلاثية الأبعاد للهاتف مبني بـ Godot.

## الموجود الآن
- نحت التضاريس: رفع وخفض.
- تنعيم التضاريس.
- طلاء الأرض بأي لون عبر Color Picker.
- مكتبة جاهزة: 3 أشجار و3 صخور.
- حذف العناصر القريبة.
- شمس وظلال وسماء.
- كاميرا دوران + تكبير بإصبعين.
- حفظ وفتح الخريطة محليًا.
- تراجع حتى 12 خطوة.
- دعم ARMv7 وARM64 ليتوافق مع أجهزة أندرويد القديمة والجديدة.

## التحكم
- اختر أداة من الشريط السفلي.
- مع أدوات النحت/الطلاء: المس أو اسحب على الأرض.
- مع الأشجار والصخور: اختر النوع ثم المس المكان.
- أداة الكاميرا: اسحب بإصبع واحد للدوران، واستخدم إصبعين للتكبير والتصغير.
